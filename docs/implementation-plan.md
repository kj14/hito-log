# MVP 実装計画（人生時間可視化システム）

## 目的
設計ドキュメントで定義した MVP 範囲（個人カウントダウン、関係登録と静的共有時間試算、目標必要ペース表示）を Next.js + TypeScript 上で体験できるプロトタイプとして実装する。

## スコープ
- フロントエンドのみ（ローカル状態管理）。
- サンプルデータを初期化し、ユーザー操作で更新可能にする。
- 主要計算ロジックはユーティリティ関数として切り出す。

## タスク分解
1. **ユーティリティ整備**
   - 年齢・経過時間・残余時間・会合回数・目標ペースの計算関数を TypeScript で実装。
   - 型定義を共通化し、将来的な Supabase モデルに接続しやすい構造にする。

2. **UI コンポーネント実装**
   - ライフカウントダウン: 現在時刻からのリアルタイム残り時間を表示するコンポーネント。
   - 関係共有タイム: 関係リストの CRUD (作成・削除) と共有時間試算結果を表形式で表示。
   - 目標トラッカー: 目標の必要ペース／予測完了日を表示し、実績ログ入力を受け付ける。

3. **ページ統合**
   - `src/app/page.tsx` を MVP のダッシュボード構造に差し替える。
   - セクション間のレイアウト、カード、見出し、説明テキストを整備し、Tailwind で簡易スタイルを付与。

4. **追加調整**
   - 視覚的に区切るためのユーティリティクラスやレスポンシブ対応を最低限整備。
   - ドキュメントと実装の整合性を確認し、必要に応じてコメントを追記。

## 成果物
- プロトタイプ UI を備えたトップページ。
- 計算ロジックの共通化されたユーティリティ群。
- 今後のバックエンド接続に備えた型定義の雛形。
